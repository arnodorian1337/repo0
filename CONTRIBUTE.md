# Contributing

Thank you for your interest in contributing to this project!

## How to contribute

1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Commit your changes with descriptive messages.
4. Push to your branch and submit a pull request.

## Reporting Bugs

If you find a bug, please open an issue on the GitHub repository and include as much detail as possible to help us reproduce it.

## Pull Request Process

- Ensure your code follows the project style.
- Update documentation as necessary.
- The PR will be reviewed by the maintainers.
